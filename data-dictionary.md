# Data Dictionary

| Field | Purpose |
|---|---|
| Business Name | Current public business name |
| Category | Primary product/service category |
| Address | Current public business address |
| Distance from Target | Verified distance or qualitative location note |
| Locally Owned? | Evidence-based local/independent ownership status |
| Decision-Maker | Publicly identified person responsible for relevant decisions |
| Title | Public title, if available |
| Decision-Maker Confidence | Verified, Needs Research, or Conflicting |
| Phone | Public business phone |
| Business Email | Public business email only; never inferred |
| Student Opportunity | Why the business may be relevant to students |
| Existing Student Discount? | Yes, No Offer Found in Sources Reviewed, or Needs Research |
| Potential Student Offer | Possible idea, not a promised offer |
| Why This Business Could Benefit | Evidence-based business-development rationale |
| Status | Human workflow status |
| Movement Opportunity Type | New offer, extend existing offer, multi-vendor partnership, etc. |
| Movement Outreach Angle | Personalized reason to start the conversation |
| Suggested Opening | Suggested first sentence or opening question |
| What Not To Assume | Important guardrails or unresolved issues |
| Mary's Next Move | One practical next action for the human reviewer |
| Sources / Research Notes | URLs, source names, dates, and verification notes |
